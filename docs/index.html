Every AI chat you've
ever had, in one place.

aiyou harvests your Claude Code, OpenCode, Codex, Copilot, Cursor and friends into one normalized, git-versioned store — imports your ChatGPT & Gemini dumps — then runs an LLM swarm over everything to write a SKILL.md that makes every agent align with you.

Get started ★ on GitHub

One store. Zero lock-in.

Your agents' data lives in a dozen opaque SQLite files and JSONL dumps. aiyou turns all of it into a plain, diffable git repo on your disk.

🧲

Harvest everything

16 harness adapters — JSONL, SQLite, VS Code state dbs — all read-only, incremental and idempotent. Run it from cron; only what changed gets re-exported.

📦

Progressive imports

Drop in ChatGPT, Claude.ai or Gemini Takeout dumps as often as you like. Same conversations update in place — never a duplicate, every import audited in a manifest.

🐝

Profile swarm

A map-reduce LLM swarm distills personality, preferences, workflow and values into traits.json + a portable SKILL.md. Incremental — only new chats get analyzed.

🔐

Local-first & redacted

The store is a plain git repo — add your own remote if you want backups. API keys are redacted from exports before anything ever leaves your machine.

Supported harnesses

Missing one? It's skipped quietly. Sources are plugin adapters — a trait with three methods.

Install

Pick your poison — Arch (AUR), Debian/Ubuntu, Fedora/RHEL, or straight from source.

AUR 
# Arch / Manjaro
yay -S aiyou

deb / rpm 
# Debian / Ubuntu
sudo dpkg -i aiyou_0.2.0_amd64.deb
# Fedora / RHEL
sudo dnf install aiyou-0.2.0-1.x86_64.rpm

source 
git clone https://github.com/geniusrise/you && cd you
cargo install --path .        # or: cargo install --git https://github.com/geniusrise/you

Four commands to alignment

Init the store.
aiyou init — creates ~/.aiyou, a git repo with your config.

Harvest + import.
aiyou sync pulls every local harness. aiyou import chatgpt ~/dumps.zip merges hosted chats, progressively.

Run the swarm.
aiyou profile — any OpenAI-compatible endpoint — writes traits.json + SKILL.md, incrementally as data evolves.

Install the skill.
aiyou profile install --target claude (or opencode, crush, codex). Now every agent knows you.


cron 
# keep everything fresh (aiyou cron prints this for you)
0 3 * * *  aiyou sync
0 4 * * 0  aiyou profile --if-changed
