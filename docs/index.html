Your agents don't know you.
Teach them once.

aiyou reads how you actually talk, decide and work across every AI tool you use, distills your personality, taste and habits into one me skill, and keeps it current as you change — nothing updates until you approve it. Every agent you run then works the way you would.

# ~/.aiyou/profile/SKILL.md  (excerpt)
## How to talk to me
- Wants answers under five lines unless I ask to elaborate
- Dislikes hedging; state the recommendation first, then the why
## How I like work done
- Writes the failing test first, then the implementation
- Prefers small commits with lowercase feat:/fix: prefixes
## What I value
- Boring, reliable tools over clever ones _(tentative)_

A profile that is yours, and stays right.

Not a chat archive. A living, evidence-backed model of how you want to be worked with — built from what you really said, not a form you filled in.

🧬

Extract

A map-reduce LLM swarm reads your conversations and pulls out personality, communication style, preferences, workflow, values and goals — each with evidence quotes and a confidence score. Written as instructions an agent can act on.

✅

You approve every change

New runs propose: added, updated, retired traits, shown as a diff. aiyou accept what's true, aiyou reject what isn't — rejected traits are never proposed again. Nothing reaches your agents unreviewed.

🌱

Maintained as you change

Run it from cron. Only new or changed chats are analyzed. Traits you've outgrown get proposed for retirement — an absence never deletes anything. Failed batches are retried, not forgotten.

🔌

Works with every agent

Install the me skill into Claude Code, OpenCode, Codex or Crush — or inject a managed block into CLAUDE.md, AGENTS.md or GEMINI.md without touching your own text. Or just --print it.

🔐

Local-first & redacted

Everything lives in a plain git repo on your disk, so your profile history is diffable. Secrets are redacted before anything is sent to the LLM endpoint you choose. No daemon, no hosted anything.

🧲

Fed by every chat you've had

16 read-only sources — Claude Code, Codex, Cursor, Copilot, Gemini CLI and more — plus ChatGPT, Claude.ai and Gemini dumps. More chats, better portrait.

Review, like a pull request for your personality

Every run ends in a diff you can read. Say yes to what's true, no to what isn't.

Install

Pick your poison — Arch (AUR), Debian/Ubuntu, Fedora/RHEL, or straight from source.

AUR 
# Arch / Manjaro
yay -S aiyou

deb / rpm 
# Debian / Ubuntu
sudo dpkg -i aiyou_0.3.0_amd64.deb
# Fedora / RHEL
sudo dnf install aiyou-0.3.0-1.x86_64.rpm

source 
git clone https://github.com/geniusrise/you && cd you
cargo install --path .        # or: cargo install --git https://github.com/geniusrise/you

Five commands to an agent that knows you

Init the store.
aiyou init — creates ~/.aiyou, a git repo with your config.

Gather your conversations.
aiyou sync pulls every local harness. aiyou import chatgpt ~/dumps.zip merges hosted chats.

Extract.
aiyou profile — any OpenAI-compatible endpoint — analyzes what's new and proposes changes to your profile.

Review.
aiyou review, then aiyou accept or aiyou reject. Your call, every time.

Install.
aiyou install --target claude (or opencode, codex, crush, claude-md, gemini, agents-md).


cron 
# keep the data fresh and queue proposals; you review when you like (aiyou cron prints this)
0 3 * * *  aiyou sync
0 4 * * 0  aiyou profile --if-changed
# aiyou status  ->  "pending: 3 profile change(s) — run aiyou review"
