# aiyou Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `aiyou`, a Rust CLI that harvests local agent-harness chats into one git-versioned store, progressively imports ChatGPT/Claude/Gemini dumps, and runs an incremental LLM map-reduce "swarm" to maintain a user-profile `SKILL.md`.

**Architecture:** Canonical store at `~/.aiyou` (git repo) with per-session `.jsonl` + `.md`; adapter trait for read-only harvest with fingerprint-based incremental sync; content-hash based progressive import; map-reduce profile pipeline over `.md` renders using any OpenAI-compatible endpoint; deterministic SKILL.md renderer.

**Tech Stack:** Rust, clap, serde/serde_json, toml, rusqlite(bundled), sha2, chrono, regex, anyhow, tokio, reqwest, zip, tempfile; axum only in tests (mock LLM).

**Spec:** `docs/superpowers/specs/2026-10-09-aiyou-design.md`

## Global Constraints

- Store root default `~/.aiyou`, overridable by `AIYOU_HOME` env or `--root` flag; it is a git repo; never push.
- Read-only against all sources; missing source = warn+skip, never fail whole sync; corrupt file = warn+skip.
- Canonical sources: `claude-code | opencode | codex | crush | gemini-cli | pi | chatgpt | claude-ai | gemini-import`.
- Session file layout: `chats/<source>/<project-slug>/<session-id>.{jsonl,md}`; JSONL line 1 = header `{"aiyou":"session", ...meta}`, then messages sorted by (ts,id).
- Message identity: external id else sha256 hex of `role|text|ts_ms`.
- Import conversation identity: (source, external_id) else (source, slug(title)+"-"+hash8(first user msg text)).
- Redaction regexes applied to `.md` by default; JSONL too when `redact_all = true`.
- Profile: strict-JSON trait extraction; categories exactly: personality, communication, preferences, workflow, tech-stack, values, goals; drop confidence < 0.3; cap 100 traits.
- LLM calls only in `profile`; OpenAI-compatible chat-completions API; retries ×2 with backoff.
- All tests pass with `cargo test`; no network in tests except localhost mock.
